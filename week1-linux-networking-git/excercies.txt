Exercise 1 — Find High Resource Processes
====================================================
Problem You are told: Linux server is slow.
You need to:
- identify top CPU-consuming processes
- identify top memory-consuming processes

Solution:
top
Top CPU Processes
    ps -eo pid,ppid,cmd,%mem,%cpu --sort=-%cpu | head
Top Memory Processes
    ps -eo pid,ppid,cmd,%mem,%cpu --sort=-%mem | head

Exercise 2 — Disk Usage Investigation
====================================================
Problem Disk usage reached 95%.
Find:
- largest directories
- large files

Largest Directories
    du -sh /* 2>/dev/null | sort -hr | head

Large Files
    find /var -type f -size +100M

Exercise 3 — Log Error Monitoring Script
====================================================
Problem Create a script that:
- checks logs
- counts ERROR entries

Create: vim error-check.sh

#!/bin/bash
LOG_FILE=/var/log/syslog
echo \"Checking ERROR count...\"
ERROR_COUNT=$(grep -i \"error\" $LOG_FILE | wc -l)
echo \"Total ERROR entries: $ERROR_COUNT\"

Run
chmod +x error-check.sh
./error-check.sh

Exercise 4 — Service Health Check Script
====================================================
Problem Create a script that: 
- checks if ssh service is active
- prints healthy/unhealthy

#!/bin/bash
SERVICE=ssh
STATUS=$(systemctl is-active $SERVICE)
if [ \"$STATUS\" == \"active\" ]
then
    echo \"$SERVICE is healthy\"
else
    echo \"$SERVICE is NOT healthy\"
fi

vim service-check.sh
chmod +x service-check.sh
./service-check.sh

Exercise 8 — Backup Automation Script
==================================================
Problem - Create backup of log directory.

#!/bin/bash
BACKUP_DIR=/tmp/log-backup
mkdir -p $BACKUP_DIR
tar -czf $BACKUP_DIR/logs.tar.gz /var/log
